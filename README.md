# SQL Introduktion

Undervisningsmateriale og eksempler til introduktion til SQL og dataarbejde.

## SQL er stadig fundamentet for godt dataarbejde

AI kan hjælpe med meget, men det kan ikke erstatte behovet for at forstå de data, du arbejder med. Tværtimod bliver det endnu vigtigere at kunne finde de rigtige data, kontrollere kvaliteten, kombinere datakilder og stille præcise spørgsmål til databasen.

Her er SQL stadig et af de vigtigste værktøjer.

## Hvad du lærer

- Hvordan en relationel database er bygget op, og hvorfor det giver mening
- At hente og filtrere data med SELECT, WHERE og ORDER BY
- At kombinere data fra flere tabeller med JOIN
- At opsummere og gruppere data med aggregeringer og GROUP BY
- At stille præcise spørgsmål til databasen, så du får svar du kan stole på

## Hvem er materialet for

Alle der arbejder med data og gerne vil kunne trække det ud selv i stedet for at vente på hjælp. Du behøver ingen forudsætninger i SQL.
