# SQL fra bunden - forstå og udnyt dine data

Materiale til IDA-webinaret. Online kursus, 4 intensive timer, hvor du lærer at skrive forespørgsler, udtrække data og omdanne information til brugbar indsigt.

[Arrangementsside hos IDA](https://ida.dk/arrangementer-og-kurser/arrangementer/sql-fra-bunden-forstaa-og-udnyt-dine-data-online-kursus-367816)

## Om kurset

SQL er det mest udbredte sprog til at arbejde med databaser og dataudtræk. På bare 4 timer får du en effektiv introduktion til de vigtigste begreber og kommandoer, så du hurtigt kan begynde at hente, filtrere og analysere data fra en MySQL-database.

Kurset er hands-on og rettet mod dig, der gerne vil forstå databaser og kunne arbejde direkte med data, uanset om du er nybegynder eller har arbejdet lidt med data før. Du starter fra bunden og ender med selv at kunne skrive forespørgsler, der trækker indsigt ud af dine data.

## Formål

Kurset sætter dig i stand til at:

- Forstå, hvordan relationelle databaser fungerer
- Skrive grundlæggende SQL-forespørgsler i MySQL Workbench
- Hente, filtrere, sortere og kombinere data fra én eller flere tabeller
- Bruge SQL som værktøj i dataanalyse, rapportering eller udvikling

## Form

Kurset veksler mellem korte oplæg, konkrete eksempler og praktiske øvelser, så du får både teori og erfaring. Undervisningen foregår i MySQL Workbench og tager udgangspunkt i realistiske datasæt fra demodatabasen Northwind.

## Agenda

**Del 1 - Grundlæggende SQL-syntaks**
- Hvad er SQL og relationelle databaser?
- SELECT, FROM, WHERE - de tre vigtigste kommandoer
- Filtrering med logiske operatorer (AND, OR, IN, BETWEEN, LIKE)

**Del 2 - Sortering og begrænsning**
- ORDER BY og LIMIT

**Del 3 - Flere-tabelforespørgsler**
- JOINs
- Relationer mellem tabeller

**Del 4 - Aggregerede data og grupperinger**
- GROUP BY og HAVING
- SUM, COUNT, AVG med flere
